# WP Themes

WordPress theme workspace.

## Themes

- `wp-theme-starter`: Shared parent theme with classic PHP templates and block editor design settings.
- `ur-promoter`: Child theme for UR Promoter.
- `fudawang`: Child theme for Fudawang.
- `jyc-foundation`: Child theme for JYC Foundation.
- `aplus-age`: Child theme for Aplus Age.

See `ARCHITECTURE.md` for the multi-site theme strategy.

## Development Notes

Each theme should live in its own folder and include at least:

- `style.css` with a valid WordPress theme header
- `index.php`
- `functions.php`
- required templates and assets
