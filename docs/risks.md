# 風險與相容性評估

| 風險 | 控制及驗證 |
| --- | --- |
| DB Global Styles 遮蔽檔案更新 | 記錄套用版本與自訂狀態，保留匯出／截圖；人工重新套用前先備份，不自動合併 |
| DB 模板遮蔽新版模板 | 測試檔案模板及已自訂模板，提供原生重設說明 |
| Sydney 改為 Block Theme | 只在副本盤點選單、小工具、額外 CSS、首頁、短代碼；此專案不授權正式切換 |
| 任意手動主色造成低對比 | 配色文件列出有效配對，調色後重新檢查；不宣稱自動產生安全對比色 |
| 外掛 CSS、高權重、iframe、Shadow DOM | 先讀碼與查 DOM，再限定 adapter；不保證全部繼承 |
| 快取或 PWA 保留舊資源 | 使用版本化資源並驗證清除各層快取，檢查登入隔離 |
| UR 副本含個資與外連副作用 | 匯入前去識別、禁止索引、關閉真實寄信、排程抓取與付費 API；不提交副本 |
| 版本與主機差異 | 鎖定測試矩陣，未測版本不列支援 |
| 測試副本未取得 | 不阻止 M0/M1 示範；M2 的 UR 實測維持待驗 |

## 相容性矩陣

- WordPress：首輪 7.1.4；實作時重新查修補版，變動記錄於報告。
- PHP／資料庫：尚未盤點，M1 環境建立時核對官方要求與部署目標。
- 編輯器：WordPress 原生區塊編輯器，不依賴 Gutenberg 外掛或 Elementor。
- 瀏覽器：實作當時 Chrome、Firefox、Safari、Edge 穩定版，記錄確切版本；手機驗證 iOS Safari 與 Android Chrome。
- 顯示寬度：360、390、768、1280px；另測 200% 縮放、鍵盤、焦點、減少動態效果與橫向捲動。
- 既有外掛：UR AI Assistant 待原始碼；其他外掛皆未驗證。

整體架構可行；目前無執行證據可保證效能優於官方或 Sydney。
