== Description ==

WP Theme Starter is a minimal classic WordPress theme scaffold for custom theme design and development.

== Installation ==

1. Copy the `wp-theme-starter` folder to `wp-content/themes/`.
2. In WordPress admin, go to Appearance > Themes.
3. Activate WP Theme Starter.
