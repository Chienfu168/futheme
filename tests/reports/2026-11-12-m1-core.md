## 發現並已修正

- 首頁「最新消息」標題為寬版、文章格線卻被限縮在內文寬，左右不對齊 → query 改 default layout。列表頁統一為內文寬。
- WP-CLI 不帶 `--user` 寫 Global Styles 時文章不掛佈景分類，每次新建一篇（測試工具問題，非佈景問題）→ 工具註明必須帶 `--user`。

## 未測／限制

- **網站編輯器 UI** 未操作：切換是直接寫入 Global Styles 文章，等同儲存的結果，但沒有在「外觀 → 編輯器 → 樣式」實際點選；編輯器畫面與前台是否一致未驗證。
- **資料庫**：SQLite 模擬，非正式主機的 MySQL/MariaDB。
- **首頁沒有 `<h1>`**：待「橫幅」項目的 hero 補上。
- Firefox、Safari、手機實機、200% 縮放、對比的實際 DOM 檢查、效能比較：未測。
- `Requires PHP: 8.3` 是因為只測過 8.3；正式主機 PHP 版本未盤點，若較低需另測後再放寬。
- theme.json 的翻譯字串（色名、字級名）因 `make-pot` 需連 develop.svn.wordpress.org 被擋，以 `--skip-theme-json` 產生 POT，這些字串手動維護在 zh_TW.po。
