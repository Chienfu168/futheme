# 0.2.1 導覽「未指定選單」保護（2026-11-16）

## 問題

使用者在 fudawang 換上 FuTheme 後截圖：頁首導覽擠成 7 行、頁尾列出一長串頁面。
原因：頁首、頁尾的 Navigation 區塊沒有指定選單時，WordPress 會自動列出**所有已發布頁面**（Page List 備援）。fudawang 有 30 多頁，全部被排進選單。

## 做法（functions.php）

只在「區塊沒有 `ref`、沒有內含項目、走自動備援」且備援項目超過上限（預設 6，可用 `futheme_fallback_nav_max_items` 濾鏡調整）時介入：

| 位置 | 判斷 | 行為 |
| --- | --- | --- |
| 頁首 | `overlayMenu` 不是 `never` | 改為 `always`：收成選單按鈕，點開仍可到達所有頁面 |
| 頁尾 | `overlayMenu` 為 `never` | 不輸出自動清單（頁首已可到達所有頁面） |

項目數：Page List 只算最上層頁面（子頁面收在子選單）；其他備援（既有的 wp_navigation）算最上層區塊數。結果以 static 快取，每次請求只算一次。
站長在網站編輯器指定選單後，這段不作用。沒有新增公開 Token 或 fu- 類別。

## 驗證（WordPress 7.1.4、PHP 8.3.6、SQLite、Chromium）

| 情境 | 結果 |
| --- | --- |
| 36 頁、未指定選單（修正前） | 頁首導覽高 379px（1280 寬）、頁尾 1671px，重現問題 |
| 36 頁、未指定選單（修正後） | 頁首 24px 選單按鈕；點開顯示 36 個連結、Esc 關閉；頁尾不輸出；無 JS 錯誤、無 PHP 錯誤記錄 |
| 4 頁、未指定選單 | 不介入：頁首 1280 寬照常橫排 4 項，頁尾直列 4 項 |
| 36 頁、頁首指定 2 項選單 | 不介入：頁首 2 項；頁尾備援改用該選單 2 項照常顯示 |
| PHP lint | 通過 |
