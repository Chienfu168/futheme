# 0.3.0 預設橫幅圖、頁尾與頁首選單按鈕（2026-11-16）

使用者回報「頁首頁尾都不正常」，並要求增加預設橫幅圖。無法連到 fudawang 查看實際畫面（雲端容器連線被擋），以本機測試站 37 個頁面、未指定選單的情境重現。

## 改動

| 區域 | 做法 |
| --- | --- |
| 預設橫幅圖 | `assets/images/banner-1920.webp`（7.9KB）、`banner-960.webp`（3.7KB），以 [make_banner.py](../../scripts/make_banner.py) 產生的原創灰階抽象城市剪影，無外部素材。`.fu-banner` 沒有圖片時，`render_block_core/cover` 插入 `<img>`（srcset、寬高、`fetchpriority="high"`），遮罩為 80% primary，圖跟著配色變色。首頁、單篇、單頁都適用；站長設定圖片或精選圖片後以站長的為準 |
| 頁尾 | 左：網站名稱＋副標題；右：選單（直列、間距縮小）；下：細線＋「© 今年 網站名稱」。`.fu-copyright` 的年份在前台換成今年，儲存後也不會過期 |
| 頁首 | 未指定選單且頁面過多時，收合按鈕改顯示文字（中文站為「選單」）而非只有圖示 |
| 版本 | 0.2.1 → 0.3.0 |

## 驗證（WordPress 7.1.4、PHP 8.3.6、SQLite、Chromium）

| 檢查 | 結果 | 方法 |
| --- | --- | --- |
| 橫幅文字對比 | 通過（計算值） | 圖片實際亮度 58–153，以 45–170 保守計算：80% primary 遮罩下 primary-contrast 最低 4.81:1（classic-gold）；75% 只有 4.59:1，故取 80% |
| 預設圖載入 | 通過 | 1280 寬載入 1920 版、360 寬載入 960 版；遮罩 computed `opacity 0.8`、primary 色 |
| 編輯器區塊合法性 | 通過 | [editor-validity.js](../tools/editor-validity.js)：8 個模板＋頁首頁尾全部 `isValid`（頁尾 9 個區塊） |
| 版面 | 通過 | 360／1280 無橫向溢出；未指定選單、指定 4 項選單兩種情境截圖；JS 錯誤 0 |
| 配色 | 目視 | creative-purple、classic-gold、coral-red、graphite 截圖；coral-red 主色較亮，城市剪影較淡但文字清楚 |

## 限制

- 編輯器內的橫幅仍顯示主色實心（預設圖只在前台插入）。
- 站長若曾在網站編輯器修改並儲存頁首／頁尾，資料庫的版本會蓋過佈景檔，需在編輯器對該範本組件「重設」才會看到新頁尾。
- 未在 fudawang 或其副本測試；只測 Chromium。
